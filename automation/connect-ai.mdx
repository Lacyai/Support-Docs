**Connect AI** links Claude or ChatGPT to your Lacy.ai account. Once connected, you can describe what you want to do in chat and use the tools available to your account.

- “Draft an inbound receptionist that answers common questions and collects callback details.”
- “Review my most recent campaign call and tell me why it ended.”
- “Show me the settings for my follow-up campaign before I start it.”

<Info>
  Connect AI uses a remote Model Context Protocol (MCP) server with OAuth 2.0. You sign in to Lacy.ai and approve the connection. The tools you can use depend on your Lacy.ai permissions and your chat app.
</Info>

To let a Lacy.ai phone agent use external tools during a call, see [MCP Servers](/ai-assistants/mcp-servers).

## Before you start

You’ll need access to your [Lacy.ai account](https://app.lacy.ai/) and permission to add a custom connector in Claude or ChatGPT. For a managed workspace, an administrator may need to add or approve the connection.

### Your connection link

Copy this URL for either app.

```text
https://app.lacy.ai/mcp
```

## Add the connector

<Tabs>
  <Tab title="Claude">
    <Steps>
      <Step title="Open Connectors">
        In Claude, go to **Customize → Connectors**.
      </Step>
      <Step title="Add a custom web connector">
        Select **Add**, then choose the custom web connector option. Enter **Lacy.ai** as the name and paste the connection link.
      </Step>
      <Step title="Sign in to Lacy.ai">
        Continue through the authentication setup and add the connector. If you see a **Connect** button, select it to start sign-in. Approve the connection when Lacy.ai prompts you.
      </Step>
      <Step title="Enable the connector in a chat">
        Start a chat, open the **+** menu, and enable **Lacy.ai** under **Connectors**.
      </Step>
    </Steps>

    See [Claude’s custom connector instructions](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp) for workspace permissions and setup options.
  </Tab>
  <Tab title="ChatGPT">
    <Steps>
      <Step title="Open Plugins">
        In ChatGPT on the web, open **Plugins**, select **+**, then choose **Add custom MCP server**.
      </Step>
      <Step title="Enter the connection details">
        Name the connection **Lacy.ai**, paste the connection link under **Connection**, and select **OAuth** for authentication.
      </Step>
      <Step title="Create the plugin and sign in">
        Review the prompt, select **Create as a plugin**, and sign in to Lacy.ai when asked. Review the discovered tools.
      </Step>
      <Step title="Use Lacy.ai in a chat">
        Select **Lacy.ai** when starting a chat where you want to use the connector.
      </Step>
    </Steps>

    If your workspace uses the older Apps interface, go to **Apps → Create**, enter the same URL, choose **OAuth**, and select **Scan Tools**. Sign in when prompted, then save the app. See [ChatGPT’s custom MCP instructions](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt) for workspace permissions and support for read and write actions.
  </Tab>
</Tabs>

## Security and privacy

- **Sign-in.** Approve access through Lacy.ai’s OAuth sign-in. Setup requires no Lacy.ai API key.
- **Account access.** The connection uses the Lacy.ai account you sign in with. Review the tools available to the chat app before using it with customer data.
- **Account changes and usage.** Review changes before approving them. Actions such as placing calls or sending messages may use your account balance.
- **Disconnecting.** Disable or remove the Lacy.ai connection in your chat app’s connector or plugin settings.

## FAQ

<AccordionGroup>
  <Accordion title="Why can’t I add a custom connector?">
    Check your chat app’s plan and workspace permissions. If your workspace is managed, ask the administrator to add the connector or grant access.
  </Accordion>
  <Accordion title="What if sign-in fails or the tools don’t appear?">
    Confirm that the connection URL is `https://app.lacy.ai/mcp`. Reconnect from the chat app’s settings, sign in to the intended Lacy.ai account, and enable the connector in a new chat.
  </Accordion>
  <Accordion title="Why is a specific action unavailable?">
    Check your account permissions and the tools enabled in your chat app. You can also complete the task directly in the [Lacy.ai dashboard](https://app.lacy.ai/).
  </Accordion>
</AccordionGroup>
